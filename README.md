# DDIEGO Y2K FX — GitHub Ready V3

Windows VST3 build with GitHub Actions.

1. Upload all files/folders in this project to the repository root.
2. Open GitHub → Actions → Build VST3.
3. Click Run workflow.
4. Wait for the green check.
5. Open the successful run and download the artifact `DDIEGO-Y2K-FX-VST3`.

JUCE is downloaded automatically during the build.
